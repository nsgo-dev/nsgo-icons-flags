## [0.1.0] - 2026-11-26

- Require NSGo v0.3.4 and Go 1.27.3, so an app that adds the flags stays on a released NSGo.
- Add the 271 flags of flag-icons 7.6.0 for NSGo, in 4:3 and 1:1, one accessor per flag and ratio.
- Add `catalog` to find a flag by a code known at run time, with each flag's English name, capital and continent.
- Draw the stars of the United States and the U.S. Minor Outlying Islands, which upstream draws with SVG markers that NSGo does not support.
- Add a gallery that finds flags by name, code or capital and shows the code that draws the chosen one, ready to copy.
- Add a website on GitHub Pages, with highlighted code in light and dark, a favicon, and link previews for search and social sites.
